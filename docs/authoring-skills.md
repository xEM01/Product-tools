# Authoring skills

1. Copy `skills/_template` to `skills/<kebab-case-name>`.
2. Edit `SKILL.md`: `name` must match the folder; the `description` decides when the skill triggers, so be specific.
3. Keep SKILL.md concise; move long material to `references/`.
4. Add the skill to the table in the root README.
5. Run `python scripts/validate.py` before committing.
